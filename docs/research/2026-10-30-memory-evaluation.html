Agent memory: measured behavior and options

Research snapshot · 30 Oct 2026 · Primary sources linked below

Finding: explicit project-scoped memory and stale-source filtering work in the local checks. On a separate small live confirmation set, embeddings improved answerable recall with no false positives; Clef answered the known questions but over-answered half the intentionally ambiguous cases. Keep production FTS and the stale-source prompt filter; this evidence does not justify automatic semantic memory injection.

Keep the cache types separate

  • Provider prompt cache: provider-side reuse of stable prompt prefixes; policy, keys, and benefits belong to the provider API.
  • Semantic response cache: approximate reuse of prior answers by similar query; can serve wrong or stale answers and needs its own invalidation/evaluation.
  • Revision-aware source cache: stores explicitly selected source bytes by project/revision/hash; useful for repeat reads and provenance, not meaning-based retrieval.
  • Durable memory: explicit, versioned facts with scope, source, expiry and correction/deletion rules; search can be lexical or semantic. Current ContextStore implements a conservative lexical variant.

Recommendation

Keep the small explicit-write SQLite layer, source references, untrusted label, and stale-source prompt filter. Keep production FTS as the default: its strict abstention is safer than BM25 OR on this fixture. The BGE results are promising but small; Clef’s ambiguous false answers make automatic semantic injection too risky to enable by default. Do not change runtime retrieval from these measurements alone. A later opt-in experiment can evaluate semantic fallback with representative user queries and a larger ambiguity set.

Broader evaluation should test memory inside multi-session tasks, not only string lookup. MemoryAgentBench evaluates retrieval, learning, long-range understanding and forgetting; MemoryArena reports that strong long-context benchmark results can fail to transfer to interdependent agent tasks. These papers motivate a later model-backed evaluation; this free run makes no SOTA claim.
